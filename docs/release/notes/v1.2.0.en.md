## New: automatic update checks

- Mist checks for a new version shortly after it starts, then once a day. It only lets you know: nothing is installed until you click, and Mist never restarts on its own.
- Check any time with **Help → Check for Updates…**. The About Mist window shows when Mist last checked.
- On Linux and Windows you can update from inside Mist with one click. The download is verified first, and after installing you just click **Restart Now**. Mist test-runs the new version before switching to it, so if something is wrong your current version stays as it is.
- On macOS, updating is still manual for now: Mist tells you when a new version is out, and **Open Download Page** takes you to it.
- Don't want update checks? Clear **Check for updates automatically** in **Preferences → General**. A check sends only the Mist version and system type, with no account or device information.
- From the terminal: `mist update --check` to see if there is a new version, `mist update` to update, and `mist update --rollback` to go back to the previous version.
