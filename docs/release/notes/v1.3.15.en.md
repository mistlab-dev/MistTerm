# MistTerm 1.3.15

## What's new

- Directory inheritance for new tabs and splits now comes from the shell itself (OSC 7 / 9;9 and iTerm2's OSC 1337) instead of being guessed from the prompt text, which could mistake an ordinary word in the prompt for a directory
- When the server has no shell integration installed, MistTerm adds a directory-reporting hook after connecting: it only affects the current session, writes nothing to the server, and disappears when the session ends; nothing is added if it is already present. Can be turned off under Preferences → Connection
- Inheritance now compares the remote host name together with the login name, so a session under a different account on the same machine is no longer treated as inheritable and no longer changes into a directory it has no access to
- Fixed: a startup directory beginning with `~` (for example `~/project`) made the inherited `cd` fail
- Fixed: if the remote program had bracketed paste enabled when the connection dropped (a crashing vim, say), pasting after reconnecting was sent wrapped in escape sequences
- Fixed: resizing the window sent a size change to the remote on every step, making full-screen programs such as vim and htop redraw constantly and the drag feel sluggish; now throttled to 100ms while the local grid still updates immediately
