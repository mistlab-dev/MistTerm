# MistTerm 1.2.36

## What's New

- **Bitmap-only fonts no longer quit the app**: Selecting macOS **GB18030 Bitmap**, and other outline-less bitmap TTFs, no longer panics or exits. Those fonts are filtered out of the terminal font list. A saved preference that points at one falls back to the system default monospace.
- **Crash observability**: Recording similar aborts in local logs is still tracked in issue #150. This release does not include that work.
