# MistTerm 1.3.14

## What's new

- New preference: show the host in terminal tab titles (on by default; turn it off to show only the session name)
- Welcome screen buttons are centered with clearer copy; "Open a saved connection" now expands the left connection sidebar and focuses search instead of opening a separate picker
- Edit / New connection dialogs fill the full column width, removing the empty gap on the right
- The system monitor toolbar wraps to three rows so "Refresh" is no longer clipped in a narrow panel
- The connection sidebar search box now uses the same framed style as settings inputs
- Saving a changed session port now notes that already-connected tabs keep the old port until you reconnect, and saving no longer auto-connects
- Fixed: the sidebar occasionally showed two rows for the same session
- When a session has a custom name, the tab shows just the name without appending the IP
- One-time explanations in Automation rules and the file panel moved into the title-bar "?" instead of taking a line of body text
