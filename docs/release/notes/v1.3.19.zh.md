# MistTerm 1.3.19

## 更新内容

- 文件面板里，标题、路径和工具栏之间不再多出空白带，右边缘也不再留一条细缝
- 确认框里按回车或空格，会执行蓝色的主按钮
- 为命令片段录制快捷键时，只按修饰键不会提前结束；可以完整录下并使用带 Shift 的组合键
- 「填写变量」弹窗会把命令里真正要替换的占位符放在最显眼的位置，输入后命令预览会跟着变；如果这项不会改写命令，也会明白告诉你
- 编辑从未保存过密码的会话时，密码框不再预先显示掩码，看起来不像已经存了密码
- 设置 → 关于与更新里，未选中的更新渠道会显示出单选圆环
- 标签和连接列表里的 IPv4 地址小数点更清楚，例如 127.0.0.1 不会再看起来像 127.0.01
- 切换更新渠道后，「上次检查更新」会马上显示当前渠道自己的状态
- 从偏好设置里检查更新时，「软件更新」对话框会显示在设置窗口上面，不用先关掉设置
- 英文界面下，文件面板保持默认宽度时，「Compare folders」可以完整显示并点到
- 操作审计、云端同步和文件面板里的中文说明词组（例如「审计目录」「上传」「请换路径」）不会被拆开换行
- 打开的标签太多时，标签栏可以左右滚动；新标签或当前标签会自动滚到能看见、能点到的位置，不必先最大化窗口或收起侧栏
