# MistTerm 1.3.9

## What's New

- **macOS normal-window tab bar visible**: Transparent title bar so the custom tab bar is no longer covered by an opaque system title bar; fixes the root cause that still failed in 1.3.7 (#325 / #331).
- **Reconnect no longer opens as a split**: On macOS, reconnect and split-pane actions are mutually exclusive in the same frame, so reconnect no longer races into a split (#326 / #332).
- **macOS ⌘C / ⌘V and Edit → Copy**: After egui-winit 0.37, command-only Copy/Paste events are recognized again; selection copy also writes the system clipboard reliably (#336 / #338).
- **Honest shortcut labels; About no longer steals ⌘H**: Remove fake ⌘K / ⌘⇧S labels from Snippets and SFTP; Preferences shows ⌘,; About moves off ⌘H so Hide Window works (#339).
- **Crash dialog only for a real new report**: Unclean exit with no new `crash-*.log` no longer shows a startup notice (#334 / #340).
- **Empty state “Open existing connection”**: When saved hosts exist, the empty workspace offers a third CTA to open one in a new tab (#335 / #341).
