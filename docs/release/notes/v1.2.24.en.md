# MistTerm 1.2.24

## What's new

- **Default local folder**: Preferences → General has a new Default local folder; type a path or pick one with Browse…, or leave it empty to use your system Downloads folder. The SFTP local pane and sz downloads both use it, so they no longer open in an empty temp folder.
- **Top-rounded tabs everywhere**: tabs look the same in light and dark themes.

## Fixes

- **No more garbled CJK input**: SSH sessions now send your local locale (`LANG`/`LC_*`) to the server, falling back to `en_US.UTF-8` when none is set, so typed or pasted Chinese echoes correctly in mysql and similar tools. Note: the server's `sshd_config` needs `AcceptEnv LANG LC_*` (default on Ubuntu/Debian); without it the stock ssh client garbles too.
- **No more `//` in paths**: the SFTP remote path bar shows `/root` instead of `//root`.
- **Light-theme SFTP red overlays gone**: the local and remote file table headers no longer share a widget ID, so switching themes no longer shows red warning boxes.
