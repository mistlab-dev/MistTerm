# MistTerm 1.2.35

## 更新内容

- **Linux 桌面包只有 Mist**：`Mist-linux-x86_64.tar.gz` 里只有 `Mist`。命令行用 `mist-cli-linux-x86_64.tar.gz` / `mist-cli-linux-aarch64.tar.gz`，或 `curl -fsSL https://mistlab.dev/install | bash`。目录里若还有旧的 `mist`，先删掉再检查更新，或重新解压。
- **Mac 按架构下载**：主下载是 `Mist-macos-aarch64.dmg`（Apple Silicon）。Intel 用 `Mist-macos-x86_64.dmg`。不再提供 universal。已经装了 universal 的，先手动换一次对应架构的 dmg，之后才能一键更新。
- **体积说明**：细节和体积表见 `docs/release/PACKAGE_SIZE.md`。
- **会话导入可在设置里开关**：导入 ssh_config 和外部会话改成内置模块，和其他内置能力一样可在偏好设置里关掉。关掉后导入入口不可用；已经导入的会话还在。
- **系统程序路径不再变成链接**：`/usr/bin`、`/bin` 这类系统二进制路径不再画下划线。配置和自己的路径仍可点击。
- **双击选中 base64 末尾的等号**：双击 `YWJjZA==` 这类内容时，末尾的 `=` / `==` 会一起被选中。
- **暗夜里未选中的标签更好认**：暗夜主题下没选中的标签对比更高。侧栏没有会话时，空状态有可点的「新建会话」。
- **设置里的数字步进器再矮一点**：表单步进器在 1.2.34 的基础上再收紧一档。
