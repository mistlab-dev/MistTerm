# MistTerm 1.2.21

## What's new

- **Side-by-side SFTP file list**: in the Night theme, local and remote files sit in two panes. The column header stays put, size and modified-time columns keep a fixed width, and file names are tinted by type.
- **Go to bookmarks and recent folders**: the toolbar Go-to menu lists bookmarked and recently opened folders, opens under the button, and no longer shows empty or duplicate paths.

## Fixes

- **Remote Up no longer clears the list**: when the current directory is `.`, MistTerm resolves the real path before moving to the parent.
- **Selecting terminal text no longer brightens the rest**: unselected glyphs are painted once, so their brightness stays the same.
