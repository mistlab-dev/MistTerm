# MistTerm 1.2.31

## 更新内容

- **高分屏上的线更细**：弹窗外框、标题分隔、标签栏分隔，以及输出里可点击文字的下划线，在 2× 屏上从 2 物理像素收到 1 物理像素。暗色弹窗描边更淡。偏好设置里的抬升卡片圆角与面板对齐，背景也没那么鼓。
- **点错误码会直接开始排查**：点输出里的错误码会把这段内容交给 AI，并自动发出排查问题；已登录团队时会马上出现 Runbook 卡片。左键点 IP 仍是复制。右键 IP 可以选择「新开连接到此 IP」，地址会填进新建连接窗口，名称留给你自己填。
- **SFTP 断线不再卡住传输**：连接断开时，正在进行或排队的传输会标成失败，并提示「连接已断开，传输已中止」。列目录失败会清掉旧列表。子系统不可用、没有权限、目录不存在、往只读目录上传，面板上显示人话。目录还在加载时按地址栏回车，会提示先等当前操作完成。
- **排障结束后可以生成复盘草稿**：在 AI 面板点「生成复盘草稿」，会根据当前终端最近的输出写成一篇 Markdown（现象、原因、处置、建议）。右侧抽屉先显示正在生成，写完再放入可编辑的标题和正文；生成失败不会留下半截文档。确认后可以「保存到 MistDocs」（用你自己的登录）。没登录团队时只保留「仅复制 Markdown」，不会自动保存。需要先启用 AI。
