# MistTerm 1.2.34

## What's New

- **Toggle built-in modules in Settings**: Official built-in capabilities can be switched on or off in Preferences. Turning one off behaves as if it were not installed.
- **Three capabilities now run as modules**: Local command check, Output Trigger (notify when a background tab finishes or errors), and display links (underline and right-click) move into built-in modules with the same behavior as before. Switching one off in Settings stops it.
- **Tighter settings layout**: Number steppers are shorter; KeepAlive interval and missed-reply counts sit on separate rows; the font menu lists monospace fonts on this machine, and listing them no longer freezes the UI. Fonts installed later show up after a restart.
