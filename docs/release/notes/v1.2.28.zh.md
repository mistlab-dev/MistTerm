# MistTerm 1.2.28

## 更新内容

- **输入法合成时 Ctrl 不再被吃掉**：正在用输入法预编辑时，Ctrl+C、Ctrl+R 等组合键会发给终端，而不是被系统吞掉。预编辑文字仍画在光标处。
- **终端聚焦时 Ctrl+J / Ctrl+K 进终端**：Ctrl+J 发给 shell（换行），Ctrl+K 发给 shell（删到行尾）。连接搜索和片段搜索只在终端失焦时占用这两个键。快速片段选择仍是 Ctrl+Shift+J / ⌘⇧J，同样只在失焦时打开。
- **快捷键说明与实测一致**：手册、关于页和软件内帮助已对齐。Ctrl+C 始终中断前台程序（SIGINT）；复制粘贴用 ⌘C / ⌘V，或 Ctrl+Shift+C / Ctrl+Shift+V。终端聚焦时 Ctrl+R 是 shell 反向历史搜索；命令历史从「工具 → 命令历史」打开，终端失焦时 Ctrl+R 也会打开该面板。
