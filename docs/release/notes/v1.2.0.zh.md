## 新功能：自动检查更新

- Mist 启动后会检查一次有没有新版本，之后每天检查一次。有新版本只会提醒你，装不装由你决定，Mist 也不会自己重启。
- 随时可以点菜单「帮助 → 检查更新…」手动检查；「关于 Mist」窗口里能看到上次检查的时间。
- Linux 和 Windows 可以在 Mist 里一键更新：下载完会先核对文件，装好后点「立即重启」就能用上新版本。安装前会先试着运行一下新版本，不正常就保持原样，你的旧版本不受影响。
- macOS 暂时要手动更新：Mist 会提醒你，点「打开下载页」下载新版本即可。
- 不想检查更新的话，在「偏好设置 → 常规」里取消「自动检查更新」就行。检查时只带版本号和系统类型，不带账号和设备信息。
- 命令行也能用：`mist update --check` 看看有没有新版本，`mist update` 直接更新，`mist update --rollback` 退回上一个版本。

## 修复

- 片段的「常用」筛选里，已归档的片段不会再排到最前面，和其他列表一样放在最后。

## 其他

- 这是第一个带自动更新的版本。从 1.1.x 升级还需要手动下载安装这一次，以后就能在 Mist 里直接更新了。
- macOS 最低要求改为 10.15（和安装说明一致）。
