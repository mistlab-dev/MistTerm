# MistTerm 1.3.18

## What's New

- When the remote side does not provide file transfer, the file panel shows a readable error; empty folders show an empty state
- On a narrow file panel, the local and remote toolbar buttons wrap to the next line so they stay visible and clickable
- When you receive a file with sz, progress and completion appear on their own, without pressing another key; a bad encoding byte no longer aborts the whole transfer, and a failed transfer ends cleanly
- When you duplicate a tab and the new session is already in the inherited directory, the login screen no longer shows two identical prompts on the same line
- New tabs and splits inherit the current directory more reliably
- In Settings → About & Updates, you can switch between the stable and preview channels. Until a preview build is published, checking the preview channel may find no available release
