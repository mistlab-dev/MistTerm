# MistTerm 1.3.3

## What's New

- **Connection list dedupes same-host entries with clearer durations**: Duplicate entries for the same host are merged, and online duration reads in plain language.
- **Fragment panel clears leftover test snippets and backfills ops starters**: Leftover test fragments are removed from the personal library; an empty library gets common ops starter fragments.
- **AI dangerous commands need a red-box confirm**: Before filling or running a dangerous terminal command, MistTerm shows a red confirmation dialog.
- **SFTP columns, icons, paths, and transfer hints**: Clearer column widths and icons, easier-to-read paths, and clearer upload/download and drag hints.
- **Monitor alerts: system notification, badge, and prefs**: Alerts can show a system notification and badge, with three-tier preference controls; disconnect errors are clearer; the alert-thresholds panel expands by default.
