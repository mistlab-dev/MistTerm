# MistTerm 1.2.30

## What's New

- **Paths, error codes, IPs, and URLs in output are clickable**: Matching text is underlined. A path opens that directory in SFTP, a URL opens in the system browser, an IP is copied, and an error code such as ECONNREFUSED is sent to the AI panel.
- **A stopped port forward stays stopped after reconnect**: Stopping a forward in the panel also removes that line from the session profile.
- **Background tabs show a bell or a disconnect**: An unfocused tab gets an accent dot when it receives a bell, or when the session ends on its own. Hover the tab for "Needs attention (bell or session ended)". The dot clears when you focus the tab.
- **Preferences are grouped into cards**: General, Appearance, and Terminal start expanded. Connection, Terminal logs, Vault, Activity audit, Team platform, and Sync & data start collapsed.
- **Update and About no longer blend together**: Centered dialogs in the dark theme use a light stroke.
- **The IME candidate window follows the cursor**: While preediting, the rectangle reported to the system input method widens with the uncommitted text, so the candidate window stays next to the cursor.
- **Known limit**: the macOS candidate window is still best confirmed on a real Mac.
