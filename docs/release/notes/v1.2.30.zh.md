# MistTerm 1.2.30

## 更新内容

- **输出里的路径、错误码、IP 和网址可以点**：这些片段会加下划线。点路径会在 SFTP 里打开对应目录，点网址用系统浏览器打开，点 IP 会复制，点 ECONNREFUSED 这类错误码会把原文发到 AI 面板。
- **停止端口转发后，重连不会再把它拉起来**：在面板里停止一条转发时，会话配置里的对应行也会删掉。
- **没在看的标签会提示响铃或断开**：后台标签收到响铃，或会话自己结束时，标签上会出现强调色圆点。悬停可以看到「需要注意（响铃或会话已结束）」。切回该标签后圆点消失。
- **偏好设置分成几张卡片**：常规、外观、终端默认展开；连接、终端日志、Vault、操作审计、团队平台、同步与数据默认折叠。
- **软件更新和关于窗口不再融在一起**：暗色主题下居中弹窗有一圈浅描边。
- **输入法候选窗跟着光标**：预编辑时，报给系统输入法的区域会按未上屏文字加宽，候选窗贴着光标。
- **已知限制**：macOS 输入法候选窗仍建议在真机上确认位置。
