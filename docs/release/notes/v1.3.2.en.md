# MistTerm 1.3.2

## What's New

- **Clearer UI copy and empty states**: Wording and empty-state hints across rules/modules, cloud sync, vault, audit, send sequences, directory compare, port forward, edit connection, monitor, snippets, history, batch exec, and session log are cleaned up for everyday use.
- **Clearer credential vault layout**: The vault uses a clearer list/edit split, so browsing and editing entries is easier.
- **Session log hints when filters match nothing**: If your filters find no log entries, MistTerm suggests what to try next instead of a blank panel.
- **Directory compare no longer falsely says both sides match**: Failures are reported honestly, and a visible placeholder shows while a scan is in progress.
- **Trust and Continue on SSH host-key change**: When a host key changes, you can trust the new key and keep connecting.
