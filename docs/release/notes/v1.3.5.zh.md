# MistTerm 1.3.5

## 更新内容

- **界面引擎升到 egui / winit 0.37**：底层渲染与窗口栈全面升级；macOS 上 Option 作 Alt、锁屏/休眠后的绘制兜底，以及输入法场景下 Control 快捷键绕过都按新栈修过；顺带清掉不再使用的旧 vendor。
- **规则编辑器「高级模式」真能切过去**：点胶囊分段会切到正则字段，再切回简单模式关键词也会回填。
- **表单控件更统一、更好认**：输入框、下拉、步进器和复选框走同一套 form kit；复选框未悬停时也看得见。
- **右侧 Dock 与选区更稳**：空壳不再整块纯黑；把右栏拖窄时选区列不会再越界崩掉。
- **macOS 编译修复**：窗口扩展改直接走 winit，本机拉最新 main 能正常编包。
