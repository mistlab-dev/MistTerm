# MistTerm 1.2.26

## 更新内容

- **多台主机时更好开标签**：标签栏「+」可直接选连接再开；侧栏与标签右键有「再开一个标签」。打开主机后连接侧栏自动收起。
- **欢迎页「新建」样式统一**：与侧栏主操作同族，主次按钮更清楚。

## 修复

- **嵌套分屏方向正确**：左右后再上下不再误成继续左右；窗格用绝对矩形摆放，左右不会被挤成上下。
- **分屏后失败卡片按钮可点**：重试 / 编辑 / 关闭不再被整窗格点击层挡住；中央已有失败卡片时不再叠同文案 Toast。
- **不再乱弹「保存为片段？」**：去掉根据成功/终端尾部猜失败路径的自动候选 Toast；入库仍用拦截 Toast 或片段分析里主动添加。
