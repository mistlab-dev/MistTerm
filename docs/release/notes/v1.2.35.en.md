# MistTerm 1.2.35

## What's New

- **Linux desktop archive contains only Mist**: `Mist-linux-x86_64.tar.gz` includes `Mist` only. The CLI is `mist-cli-linux-x86_64.tar.gz` / `mist-cli-linux-aarch64.tar.gz`, or `curl -fsSL https://mistlab.dev/install | bash`. If an old `mist` is still in the folder, delete it, then check for updates or re-extract.
- **Mac downloads are per architecture**: The primary download is `Mist-macos-aarch64.dmg` (Apple Silicon). Intel uses `Mist-macos-x86_64.dmg`. There is no universal package. If you installed the universal app, switch once to the dmg for your architecture before one-click updates work.
- **Package sizes**: Details and the size table are in `docs/release/PACKAGE_SIZE.md`.
- **Session import is a built-in module**: Importing ssh_config and external sessions can be turned off in Preferences, like the other built-ins. Turning it off disables the import actions. Sessions you already imported stay.
- **System binary paths are no longer links**: Paths under `/usr/bin`, `/bin`, and similar system locations are not underlined. Config files and your own paths can still be clicked.
- **Double-click keeps base64 padding**: Double-clicking text like `YWJjZA==` selects the trailing `=` / `==` as well.
- **Unselected tabs are easier to read in dark mode**: Unselected tabs have stronger contrast. An empty sidebar shows a clickable New session button.
- **Shorter number steppers**: Form steppers are a bit shorter than in 1.2.34.
