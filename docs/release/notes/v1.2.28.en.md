# MistTerm 1.2.28

## What's New

- **Ctrl chords during IME composition**: While an input method is preediting, Ctrl+C, Ctrl+R, and other Ctrl chords go to the terminal instead of being swallowed. The preedit string still draws at the cursor.
- **Focused Ctrl+J / Ctrl+K go to the shell**: Ctrl+J sends a line feed; Ctrl+K deletes to the end of the line. Connection search and snippet search take those keys only when the terminal is unfocused. The quick snippet picker stays Ctrl+Shift+J / ⌘⇧J, and only when unfocused.
- **Shortcut docs match measured behavior**: The manual, About page, and in-app help are aligned. Ctrl+C always interrupts the foreground program (SIGINT). Copy and paste are ⌘C / ⌘V or Ctrl+Shift+C / Ctrl+Shift+V. Focused Ctrl+R is the shell reverse-i-search; open command history from Tools → Command History, or press Ctrl+R when the terminal is unfocused.
