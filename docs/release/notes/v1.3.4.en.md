# MistTerm 1.3.4

## What's New

- **Prefs and rules buttons cleaned up**: The empty Advanced prefs fold is gone, and Manage Rules actions line up more cleanly.
- **SFTP polish**: More stable column widths, full filename on hover, and local paths without leftover tilde expansion clutter.
- **Port forwards stop and delete**: Both saved profiles and live runtime forwards can be stopped or removed directly.
- **Broader UI polish from beta feedback**: Monitor, Help, command history, session log, credential vault, menu chrome, prefs navigation, shared dialogs, AI panel, team/cloud sync, automation rules, SFTP tips, and the port-forward list all get a consistency pass for smoother day-to-day use.
