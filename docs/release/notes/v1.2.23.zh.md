# MistTerm 1.2.23

## 更新内容

- **连不上不再死胡同**：连接中可点「取消」；失败后中间有「重试 / 编辑主机 / 关闭」，按钮真能点到。
- **第一次打开更顺**：团队登录是可选的；本机 SSH 不用 mistlab 账号；帮助里写清「团队 → 登录」路径；审计/Agent 收到「帮助 → 高级」。
- **叫法统一成 MistTerm**：界面、关于、更新对话框都写 MistTerm（安装包/可执行文件仍叫 Mist，方便更新器和打包）。
- **新手命名更清楚**：「新建连接」「命令片段」「关于 MistTerm」；默认分组提示更直白。
- **快捷键不打架**：全选改成 Ctrl/⌘+Shift+A；AI 面板改成 Ctrl/⌘+Shift+I；偏好设置也可以按 Esc 关掉。
- **片段库双语标题**：界面语言是英文时，自带片段显示英文名和分类。
- **SFTP 中文错误**：本地目录不存在、拒绝连接、本机不支持 SFTP 等，中文界面下是中文说明。

## 修复

- **重连成功后的黄条会自己消失**：切到正常标签页时，粘着的重连提示会关掉。
- **本机终端不会连开两个**：欢迎页连点「本机终端」只开一个；空状态不再提「同时输入」。
- **新建连接校验更合理**：点提交后再提示必填项；本机 ssh-agent 文案按平台区分。
