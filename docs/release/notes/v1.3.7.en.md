# MistTerm 1.3.7

## What's New

- **macOS normal-window tab bar and first line**: Traffic-light positioning runs every frame in a normal window so the terminal first line no longer clips into the title bar; the session tab bar stays visible and switchable with multiple sessions.
- **Tab context-menu contrast**: Theme presets write Dark and Light together, so dark mode no longer shows light text on a white menu; items stay readable.
