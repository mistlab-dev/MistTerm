## Improvements

- **Updates download in the background by default**: when a new version is found it is fetched quietly first; you still click to install, and **Mist never restarts on its own**. If install fails, the dialog also offers **Open Download Page** for a manual install.
- **One-time preference migration**: builds that used to default “auto-download” off are switched to on once after upgrading. If you turn it off again, that choice is kept.

## Notes

- Each command snippet can still have its own shortcut in the Fragment Library (Ctrl+Shift+key on Windows / Linux, e.g. Ctrl+Shift+P; ⌘ combinations on Mac). This release does not change those rules.
