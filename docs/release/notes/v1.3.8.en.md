# MistTerm 1.3.8

## What's New

- **macOS normal-window tab bar visible**: Transparent title bar (`with_titlebar_shown(false)`) so the custom tab bar is no longer covered by an opaque system title bar; fixes the root cause that still failed in 1.3.7 (#325 / #331).
- **Reconnect no longer opens as a split**: On macOS, reconnect and split-pane actions are mutually exclusive in the same frame, so reconnect no longer races into a split (#326 / #332).
