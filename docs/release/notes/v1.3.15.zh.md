# MistTerm 1.3.15

## 更新内容

- 新标签和分屏的目录继承改为由 shell 主动上报（OSC 7 / 9;9，以及 iTerm2 的 OSC 1337），不再从提示符文本里猜路径——之前会把提示符里的普通英文片段误判成目录
- 服务器上没装 shell integration 时，连上后自动补一个目录上报钩子：只对当前会话生效、不写服务器磁盘、断开即失效；已装过的不会重复添加。偏好设置「连接」里可以关掉
- 继承判定改为按「远端主机名 + 登录名」比对，同一台机器上别的账号的会话不会再被当成可继承、去 `cd` 一个没有权限的目录
- 修复：启动目录以 `~` 开头时（如 `~/project`），继承执行 `cd` 报错
- 修复：远端程序开着括号粘贴模式时断线（比如 vim 崩了），重连后粘贴会被包成一串转义字符打进命令行
- 修复：拖动窗口时每一步都向远端发尺寸变更，vim、htop 这类全屏程序跟着反复重绘、拖动手感发涩；改为 100ms 节流，本地网格仍是即时更新
