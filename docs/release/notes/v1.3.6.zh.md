# MistTerm 1.3.6

## 更新内容

- **端口转发类型说明改成人话**：类型区常驻说明不再摊 OpenSSH 的 `-L` / `-R` / `-D`，改成「本机端口转到远端、远端端口转回来，还能开 SOCKS」这类说法；按钮与启停语义不变。
- **云端同步「团队配置」窄栏对齐**：窄栏两列布局里，「团队配置」复选框不再跟残字错列；「不含令牌」改成同行小字旁注。
- **自动化规则中文文案清理**：通知动作、帮助标题、内置规则主行和「导入 / 导出」折叠标题去掉中英混排（不再裸 Toast / Runbook / 把 JSON 摊进主标题）。
- **SFTP 设置打开更轻**：打开 SFTP 面板时改用内存里的设置，不再每次整份读盘；「知道了」写盘路径不变。
