# MistTerm 1.2.23

## What's new

- **Failed connections are no longer a dead end**: Cancel while connecting; on failure, Retry / Edit host / Close show in the middle of the tab and are actually clickable.
- **Smoother first open**: team login is optional; local SSH needs no mistlab account; Help spells out Team → Sign In; Audit / Agent sit under Help → Advanced.
- **Product name is MistTerm**: UI, About, and update dialogs say MistTerm (the binary and bundle stay Mist for the updater and packaging).
- **Clearer newbie labels**: New Connection, Command Snippets, About MistTerm; plainer Default group hint.
- **Shortcuts that do not collide**: Select All is Ctrl/⌘+Shift+A; AI panel is Ctrl/⌘+Shift+I; Preferences also closes on Esc.
- **Bilingual starter snippet titles**: with the UI in English, built-in snippets show English names and categories.
- **SFTP errors in Chinese**: local folder missing, connection refused, local terminal cannot do SFTP, and similar strings localize under zh.
- **Smaller Mac auto-update download**: one-click update on macOS now fetches only the signed Mist.app, about 47 MB instead of about 135 MB.

## Fixes

- **Sticky reconnect toast clears**: switching to a healthy tab dismisses the yellow reconnect notice.
- **Local Shell no longer doubles**: double-clicking Local Shell on the welcome screen opens one tab; the empty-state tip no longer mentions Broadcast.
- **New connection validation after submit**: required fields warn only after you try to connect; ssh-agent wording matches the platform.
