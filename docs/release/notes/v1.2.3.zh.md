## 新功能

- **常用的命令片段可以设快捷键**：在「命令片段」里编辑一条片段，点「录制」按下组合键，保存即可；不想要了点「清除」。终端里按这个快捷键，就和点这条片段一样：有变量会先问你填，照样先过团队的命令检查。快捷键只存在本机，团队片段也可以设，不影响其他成员。
  - Windows / Linux 请用 **Ctrl+Shift+键**（比如 Ctrl+Shift+Y）；Mac 请用带 **⌘** 的组合（比如 ⌘⇧Y）。
  - Ctrl+C、Ctrl+R 这类 Ctrl+键留给 shell；单个键、Shift+键、Alt/Option 组合（在终端里会打出字符或按词移动）和 Mist 自带的快捷键都不能用，录制时会直接提示原因。和别的片段撞了也会提示。

## 改进

- **Mac 上的图标大小和其他应用一致**：以前 Mist 的图标在启动台和程序坞里比别的应用大一圈，现在按苹果的标准留了边，看起来一样大。启动后程序坞里的图标也和安装包里的一致。

## 修复

- **片段删掉后快捷键还占着**：删掉个人片段或团队片段（包括别的成员删掉、同步过来的），对应的快捷键会一起去掉，不再占着这个组合键。
