# MistTerm 1.2.15

## 修复

- **行中间插入的字不显示**：光标停在已有文字中间打字（包括空格）时，内容要等回车才出来。现在立即显示，mysql 等命令行里同样适用。
- **本机终端 zsh 退格变空格**：从「访达」或程序坞打开 Mist 时本机终端没有设置 `TERM`，zsh 把退格显示成空格。现在本机终端会设置 `TERM=xterm-256color`（macOS 上没有语言设置时同时补上 `LANG=en_US.UTF-8`）。
- **macOS 应用里的程序被命令行工具覆盖**：此前 Mac 包里的 `Mist.app` 实际装的是命令行工具 `mist`，导致诊断日志开关无效。现已修正；Mac 压缩包里的命令行工具改名为 `mist-cli`。

## 诊断

- 需要排查时创建 `~/mist-debug-log` 再打开 Mist，日志写到 `~/mist-repaint.log`（只记字节数与时间，不记输入/输出内容）；排查完删掉该文件即可。
