# MistTerm 1.2.13

## Features

- **Local shell tab**: Terminal → Local Shell, or shortcut (Windows/Linux: Ctrl+Alt+T; macOS: ⌘⌥T). Also available from the top of the Connections sidebar. Opens the default local shell without saving a sidebar session.
- Local tabs reuse the existing terminal renderer; SFTP, port forwarding, and ZMODEM are unavailable (with a toast/panel message).

## Improvements

- Local shell tabs get a stable accent fill.
- Refresh third-party license notices for `portable-pty` and related crates (fixes the v1.2.12 license check failure).
