# MistTerm 1.3.13

## 更新内容

- 侧栏与标签会显示 Agent / 程序状态灯（等待 / 完成）
- 工具上报进度时，标签上会出现构建进度弧，结束后自动清除
- 终端当前目录：新开标签与分屏会从该目录启动；打开文件面板时，SFTP 可跟随目录
- 标签标题会跟随终端（例如远程主机、编辑器）；可在标签右键菜单重命名，且不会被覆盖
- 新开「本机 Shell」标签同样继承当前目录（与分屏一致）
- 应用图标已更新为扁平透明圆角品牌标
- 连接列表「已连接 N 分钟」不再把中文拆开显示
- 文件面板：长文件名中间省略；面板标题与文案中文更清晰
- 「+ 新建」放在连接侧栏搜索行右侧
