# MistTerm 1.2.29

## 更新内容

- **复制选区不再多出空格和换行**：选中并复制时，不会再补上行尾空格，软换行不会被拆成额外换行，宽字符之间也不会插入空格。Ctrl+Shift+C（Mac 为 ⌘C）、右键「复制选中」、发送到 AI 走同一条路径。
- **终端聚焦时 Alt 行编辑键发给 shell**：Alt（macOS 为 Option）+B / +F 按词跳转，Alt+D / Alt+Backspace 按词删除，Alt+. 插入上一条命令的最后一个参数。这些键不再被界面快捷键吃掉。
- **已知限制**：Alt+点击不能把光标移到点击处；也不向远端发送 xterm 鼠标协议，所以 tmux、vim 的鼠标模式不可用。鼠标仍只用于选字和滚动。
