# MistTerm 1.2.38

## 更新内容

- **交互式命令本地审计**：终端里回车提交的命令走既有本地审计，并写入 `~/.mist/logs/exec-history.jsonl`（可在偏好里开关；全屏 / 口令行 / 多行粘贴不记）。
- **命令面板**：终端失焦时 ⌘K / Ctrl+K 打开统一面板，可搜会话、片段、命令历史与应用动作。
- **OSC 133 命令块**：支持上一条 / 下一条跳转与复制当前块（Ctrl+Shift+↑/↓/O；需 shell 开启 OSC 133）。
- **粘贴历史**：记住最近成功写入 PTY 的粘贴（最多 20 条），⌘⇧P / Ctrl+Shift+P 再贴；敏感内容尽量不入库。
- **SFTP 目录对比与单向同步**：对比本机与远端差异，按勾选或全部单向复制；冲突跳过不覆盖。
- **`mist ssh --log-session`**：CLI 交互会话按命令写 JSONL（默认 `~/.mist/logs/ssh-….jsonl`）。
- **空闲光标**：已连接且聚焦空闲时按闪烁相位重绘，不再固定约 60ms 刷新。
