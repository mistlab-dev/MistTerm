# MistTerm 1.2.7

## Features

- **Team multi-host runs go through Auto-run**: after you confirm, mistlab’s control plane runs the command (plan → approve → execute). You can review results in the Console; when approval is needed, Mist shows a Console link.
- **Claim lease after remote approval**: once an admin approves in the Console, the client can finish the run without another manual step.

## Improvements

- Clearer Chinese product copy for Auto-run status (waiting, denied, failures).
