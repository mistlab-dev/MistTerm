# MistTerm 1.3.22

## What's New

- In application cursor mode, arrow keys are sent using the sequences that terminal programs expect
- The Fill Variables dialog now updates the command preview as you type, so you can insert the command as soon as you finish filling in values, without an extra rewrite step; input fields are left-aligned
- The fill dialog that opens when a command has placeholders and no saved variables yet also updates the preview as you type, and its input fields are left-aligned
- When uploading with rz or receiving with sz, you no longer need to press a key after choosing a file or starting the transfer; canceling a transfer or resizing the window also restores normal operation immediately
