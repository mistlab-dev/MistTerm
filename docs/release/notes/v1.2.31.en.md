# MistTerm 1.2.31

## What's New

- **Thinner lines on high-DPI screens**: Dialog frames, title dividers, tab-bar separators, and underlines on clickable output are one physical pixel on a 2× display (they were two). Dark-theme dialog strokes are lighter. Preference cards use the same corner radius as panels, and the fill lift is softer.
- **Clicking an error code starts troubleshooting**: The underlined error code is sent to the AI panel and the question goes out on its own. When you are signed in to a team, a Runbook card appears right away. A left click on an IP still copies it. Right-click an IP and choose "New connection to this IP" to open the new-connection dialog with that address filled in and the name left blank.
- **SFTP transfers stop when the connection drops**: In-progress and queued transfers are marked failed, with "Connection lost — transfer aborted". A failed directory listing clears the old list. Subsystem unavailable, permission denied, a missing path, and a read-only upload show plain-language errors. Pressing Enter in the address bar while a listing is still running asks you to wait.
- **A postmortem draft after troubleshooting**: "Generate postmortem draft" in the AI panel writes Markdown (what happened, cause, what you did, what to do next) from the recent terminal output. The right-hand dock shows that it is generating, then an editable title and body. A failed generation does not leave a half-written document. After you review it, "Save to MistDocs" uses your own login. If you are not signed in to a team, only "Copy Markdown" is available, and nothing is saved automatically. AI must be enabled first.
