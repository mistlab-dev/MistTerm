## Fixes

- **⌘C on Mac said "Copied" but the clipboard stayed empty**: the same happened with Ctrl+Shift+C on Windows / Linux. Copying a terminal selection with the keyboard now really puts it on the clipboard. Copy from the right-click menu always worked. This had been broken since 1.1.4.
- **Ctrl+Shift+T, Ctrl+Shift+W and Ctrl+Shift+←/→ did nothing on Windows / Linux**: you can now open a tab, close a tab and move between split panes with the keyboard. ⌘T, ⌘W and ⌘⌥←/→ on Mac were not affected.
- **Snippet shortcuts could touch the clipboard**: a snippet shortcut set on a combination such as ⌘⇧C, ⌘⇧V, ⌘⇧X or Ctrl+Shift+X could also clear the clipboard or paste once. It now just runs the snippet.

## Notes

- **Ctrl+R is left to the shell**: Ctrl+R in the terminal is your shell's own reverse history search; Mist does not intercept it. To open Mist's command history panel, use **Tools → Command History**. The manual has been corrected.
