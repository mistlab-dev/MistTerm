# MistTerm 1.2.11

## 修复

- **终端第一行不再被挡**：标签栏下面的终端第一行，任何字体和字号下都能完整显示。
- **AI 智控台**：主机状态格子不再超出面板；执行结果重新打开对话后仍按格子显示、告警主机仍标红；「新对话」按钮可用；中文界面里的英文残留改成中文；没配置 AI 时快捷提问置灰。

## 改进

- **主题配色统一**：晨曦、海洋、森林主题的筛选按钮、当前标签、选中行和片段标签，和暗夜主题样式一致。
- **Mac 支持一键自动更新**：从 1.2.11 起，Mac 版可以像 Windows 一样在应用里一键更新。下一个版本开始生效，这一次仍需手动下载安装。
