# MistTerm 1.3.2

## 更新内容

- **多处界面文案与空状态更清楚**：规则/模块、云同步、凭证库、审计、发送序列、目录对比、端口转发、编辑连接、监控、片段、历史、批量执行、会话日志等界面的中英文案与空状态提示已整理，更贴近日常用法。
- **凭证库列表与编辑分区更清晰**：凭证库改为更明确的列表/编辑分栏，浏览和改条目更顺手。
- **会话日志筛选无结果时给下一步提示**：按条件筛不到记录时，会提示可以怎么调整，而不是只剩空白。
- **目录对比失败不再误报「两边一样」**：对比失败会如实说明，扫描进行中也会显示占位，避免误判。
- **SSH 主机密钥变更可「信任并继续」**：遇到主机密钥变化时，可选择信任新密钥并继续连接。
