# MistTerm 1.2.20

## 更新内容

- **AI 回复跟随界面语言**：英文界面下，AI 助手的对话回复、解释和执行计划说明都用英文；中文界面不变。
- **AI 面板英文化**：英文界面下，AI 执行计划 / 确认流程全部显示英文——确认提示、计划状态、只读命令“不再询问”、策略解释（风险根因、建议替代、执行条件）、主机结果、规划降级提示和后续建议。
- **`mist` 命令行帮助支持英文**：系统语言（LC_ALL / LC_MESSAGES / LANG）不是中文时，`mist --help` 及所有子命令帮助显示英文；中文环境不变。

## 修复

- **AI 对话里“建议命令”为空**：`df`、`du`、`lsof`、`free`、`ps`、`journalctl` 等命令，以及六条以上的单行命令列表，之前会被漏掉；现在都会显示为可执行命令，英文小节标题大小写不同也能识别。
