# MistTerm 1.2.24

## 更新内容

- **默认本地目录**：偏好设置 →「常规」新增「默认本地目录」，可手填或点「浏览…」选择，留空即用系统「下载」文件夹。SFTP 本地窗格和 sz 收文件都用这个目录，不再每次打开都是空的临时目录。
- **标签统一顶部圆角**：浅色和深色主题的标签样式一致。

## 修复

- **中文输入不再乱码**：连接 SSH 时会把本机语言环境（`LANG`/`LC_*`）传给服务器，本机没设置时默认 `en_US.UTF-8`，mysql 等程序里输入中文回显正常。注意：需要服务器 `sshd_config` 里有 `AcceptEnv LANG LC_*`（Ubuntu/Debian 默认已有），否则系统自带的 ssh 也同样会乱。
- **路径不再显示 `//`**：SFTP 远程路径栏在根目录下显示 `/root`，而不是 `//root`。
- **浅色主题 SFTP 红框报错**：本地和远端文件表头不再撞 ID，切换主题后不再出现红色提示框。
