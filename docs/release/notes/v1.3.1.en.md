# MistTerm 1.3.1

## What's New

- **Fewer crashes when resizing tiled windows on macOS**: If the system hits a bad draw while resizing, MistTerm catches it and keeps running instead of quitting.
- **Optional reconnect when you come back**: When the window or tab is focused again, you can auto-reconnect disconnected sessions (off by default). Terminal output is kept across reconnect.
- **Clickable-link rules are editable in the app**: View, enable/disable, add, edit, or remove link rules; changes apply right away.
- **Personal rules for local command checks**: Besides built-in and team rules, you can add your own personal rules and toggle built-in ones.
- **Clearer Tools menu**: The Tools menu is grouped by purpose, with wording closer to everyday use.
