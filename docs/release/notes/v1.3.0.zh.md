# MistTerm 1.3.0

## 更新内容

- **下次打开能看到上次为什么退出**：如果上次留下了崩溃报告，再启动时会提示一次，写明版本、时间和出错的第一行。可以从提示里打开报告目录，或把全文复制下来。
- **没有新崩溃报告的异常退出也会说一声**：第一次安装不会提示。之后如果上次没有正常退出，又没有新的崩溃报告（例如进程被强制结束），下次启动仍会提示一次，说明没有新报告。正常退出后再打开则不打扰。
- **断线后终端里一直留着断开提示**：连接意外断开时，当前标签顶部会一直显示断开条，可以重连或关闭标签。开了自动重连时会显示次数和等待时间。这段时间的输入会暂存在本机，重连后可以确认是否发出。
- **输出触发规则可以在界面里改**：在「工具 → 规则管理… → 输出触发」里编辑。没改过时仍用内置规则，不会另写配置文件。保存后，下一行输出就按新规则生效。写错的正则会提示，并且不会拿去匹配。
- **登录后可以跨设备同步主机列表**：会话密码和凭证默认同步是关的。打开后，先用你设置的同步口令加密再上传（Argon2id），服务器只保存密文。另一台机器上的凭证只能用同步口令或恢复码解开，本机 device_key 解不开。口令和恢复码请自己保管；两者都丢了，云端凭证打不开，本机数据不会被删。
- **帮助菜单可以打开报告目录**：在「帮助 → 诊断」里可以打开崩溃报告目录和卡顿报告目录。
- **安全密钥登录**：会话可以选择 FIDO2 / 安全密钥。签名仍由系统的 ssh-agent 完成，应用里会提示触摸或输入 PIN。取消触摸、PIN 错误或找不到密钥时，会给出能看懂的说明。
- **连接后可以回到原来的远端现场**：编辑会话时可以填一条可选的恢复命令（例如重新挂上 tmux 或 screen）。连接或自动重连成功、shell 就绪后会执行一次。留空则什么都不做。断线时还没发出去的命令会被丢掉。
- **发送序列**：可以把多行要键入的内容存成命名序列，在当前已连接的窗口里按顺序发出，行与行之间可以设固定间隔。它和命令片段是分开的，也不会发到别的会话。
