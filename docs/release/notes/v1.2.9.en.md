# MistTerm 1.2.9

## Improvements

- **Tabs in the macOS title bar**: On macOS, session tabs now sit on the same row as the traffic-light buttons; drag the empty area to move the window, double-click to zoom. Windows/Linux unchanged.
- **Snippet card highlight**: The hover background now covers the whole snippet card, including the usage/success line.
- **Removed duplicate top-snippets list**: The redundant "Top snippets (local usage)" block is gone; counts are on each card and sorting by usage still works.
