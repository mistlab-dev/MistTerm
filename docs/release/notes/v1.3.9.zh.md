# MistTerm 1.3.9

## 更新内容

- **macOS 普通窗口标签栏可见**：标题栏透明，自定义标签栏不再被实体标题栏挡住；修复 1.3.7 仍 Fail 的根因（#325 / #331）。
- **重连不再误开成分屏**：macOS 菜单同帧竞态下，重连与分屏动作互斥，重连不再意外变成分屏（#326 / #332）。
- **macOS ⌘C / ⌘V 与「编辑 → 复制」**：适配 egui-winit 0.37 仅发 Copy/Paste 事件；选中复制也会可靠写入系统剪贴板（#336 / #338）。
- **快捷键标签对齐实际绑定；关于不再占用 ⌘H**：去掉片段 / SFTP 的假 ⌘K、⌘⇧S；偏好设置展示 ⌘,；关于改走帮助菜单，⌘H 还给系统「隐藏窗口」（#339）。
- **仅有新崩溃报告才弹异常退出提示**：异常退出但没有新的 `crash-*.log` 时启动不再弹窗（#334 / #340）。
- **空态「打开已有连接」**：有已保存主机时，空工作区增加第三个入口，点选即可开新会话标签（#335 / #341）。
