# MistTerm 1.3.6

## What's New

- **Port-forward type copy in plain language**: The always-on type blurb no longer dumps OpenSSH `-L` / `-R` / `-D`; it describes forwarding a local port out, publishing a remote port back, or opening SOCKS. Buttons and start/stop behavior are unchanged.
- **Cloud sync “Team config” aligns in a narrow column**: In the two-column layout, the Team config checkbox no longer drifts beside a wrapped leftover glyph; “no tokens” is a same-row caption.
- **Automation rules Chinese copy cleaned up**: Notification actions, help headings, built-in rule titles, and the import/export disclosure drop mixed CN/EN (no bare Toast / Runbook / JSON stuffed into the main title).
- **Lighter SFTP panel open**: Opening SFTP uses in-memory settings instead of re-reading the full settings file each time; the “Got it” write path is unchanged.
