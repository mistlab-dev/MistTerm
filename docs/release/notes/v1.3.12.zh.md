# MistTerm 1.3.12

## 更新内容

- **终端 Ctrl/⌘+滚轮调字号**：修 egui 0.37 下缩放分支失效；macOS ⌘+滚轮、Win/Linux Ctrl+滚轮步进调整终端字号并持久化，与 UI 全局缩放解耦（#372 / #375）。
- **UX 本批**（#376 / #377 / #378）：
  - 自动化规则：模块开关分层交互，内置/个人分区，避免提示挡表单
  - AI 计划卡：「放弃」「确认并执行」贴底右对齐
  - Toast：多行复制/粘贴显示行数（可选关闭 ×）
  - 命令历史：「仅成功」列表筛选
  - 系统监控：「快照发送到 AI」移出标题栏到工具条
  - 新建入口：标签栏纯 `+`；连接侧栏顶栏蓝色「+ 新建」；悬停快捷键按平台显示
- **菜单弹窗宽度**：按内容自适应，避免被初始可用宽度撑大（#373 / #374）。
