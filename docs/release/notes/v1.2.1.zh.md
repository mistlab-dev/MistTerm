## 新功能

- **从 Xshell / FinalShell 搬家**：菜单「终端 → 从 Xshell / FinalShell 导入…」，选好对方的会话文件夹，先预览再勾选导入。主机、分组、端口、用户名都会带过来，能读出的密码也一起导入；没带过来密码的会话，右键「编辑」填上即可。
- **点网页里的 ssh:// 链接直接用 Mist 打开**（Windows 和 Linux）：在「偏好设置」里找到「浏览器里的 ssh:// 链接」，点「用 MistTerm 打开」。已经保存过的服务器会直接连上；没保存过的会打开新建会话窗口并填好地址，补上密码就能连。Windows 安装版在安装时也可以勾选这一项。
- **命令行 `mist` 有了单独的 Linux 版本**：老系统（CentOS 7、Rocky 8/9、Ubuntu 20.04/22.04、Debian 12）和 ARM 服务器都能直接用，不需要装桌面相关的组件。在服务器上运行 `curl -fsSL https://mistlab.dev/install | bash` 会自动选对版本。桌面版 Mist 的系统要求不变。
- **让 Codex、Claude Code 这类 AI 助手用 `mist exec` 帮你查服务器**：`mist exec` 现在和桌面版一样先检查命令——只看不改的命令直接执行；会改动服务器的命令要你确认（或加 `--yes`）；团队规则禁止的命令直接拒绝。每条命令都会记进审计日志。配置方法见使用手册《让AI助手用mist查服务器》。

## 改进

- **AI 智控台排查时少问几次**：Mist 能更准确地认出只看不改的命令（看日志、看进程、看磁盘等）。在执行计划里勾选一下，这次排查期间同一类只读命令就不再问你；会改动服务器的命令仍然每次都要你确认。
- **「用到终端」只放进终端，不再替你按回车**：命令会放到输入行上，你看过没问题再按回车。多行命令改为复制到剪贴板。
- **确认窗口显示规则的名字**：需要确认的命令，窗口里显示命中的是哪条规则（例如「重启前确认（团队规则）」），不再显示一串看不懂的编号。

## 修复

- **Windows 一键更新失败**：有时会提示「没有权限写入」，更新装不上，还在程序目录里留下临时文件。现在已修好。更新后如果想回到上一个版本，可以运行 `mist update --rollback`；Windows 安装版（默认的“只为我安装”）现在也可以这样退回。
- **点命令片段的标题会跳过命令检查**：以前在「命令片段」面板点标题会直接执行，不经过团队的命令检查。现在和其他地方一样：该拦的会拦，该确认的会先问你。
- **「服务器侧审计不可用」提示误报**：用 IP 地址连接、而服务器上的审计程序是按主机名登记的时候，即使一切正常也会显示这条提示。现在能正确认出来。团队新加的命令规则也会在 Mist 启动后马上生效，不用再等几分钟。
- **安装审计程序的窗口给错了命令**：窗口里显示的安装命令装的是 `mist` 命令行，而不是审计程序。现在显示正确的命令。
