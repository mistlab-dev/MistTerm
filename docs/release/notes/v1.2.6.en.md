## Fixes

- **"Check for Updates" kept spinning while an update was downloading in the background**: it could take up to a day to recover, and there was no Install button. The window now shows the new version right away with "Downloading the update in the background…", and you can install as soon as the download finishes. A failed download no longer leaves it stuck either.
- **"Install Update" did nothing while the download was running**: Mist now says "Downloading the update… It will install when the download finishes." and starts installing as soon as the download is done, so you don't have to click again. The file is still checked before install; if something is wrong, Mist tells you and offers **Open Download Page**.
