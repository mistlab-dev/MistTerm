# MistTerm 1.2.15

## Fixes

- **Mid-line typing not shown**: characters (including spaces) typed with the cursor inside existing text only appeared after Enter. They now show immediately, also in clients such as mysql.
- **Backspace prints a space in the zsh local shell**: when Mist was opened from Finder or the Dock, the local shell had no `TERM`, so zsh echoed Backspace as a space. The local shell now sets `TERM=xterm-256color` (and `LANG=en_US.UTF-8` on macOS when no locale is set).
- **macOS app binary overwritten by the CLI**: `Mist.app` in previous Mac builds actually contained the `mist` CLI, so the debug log switch had no effect. Fixed; in the Mac tarball the CLI is now named `mist-cli`.

## Diagnostics

- To capture logs, create `~/mist-debug-log` before launching Mist. Logs go to `~/mist-repaint.log` (byte counts and timings only; no keystroke or terminal content). Remove the file when finished.
