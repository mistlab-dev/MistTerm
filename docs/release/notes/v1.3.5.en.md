# MistTerm 1.3.5

## What's New

- **UI stack on egui / winit 0.37**: Rendering and windowing move up together. macOS Option-as-Alt, drawRect recovery after sleep/lock, and Control shortcuts that bypass the IME path are restored on the new stack; unused stock vendor crates are dropped.
- **Rule editor Advanced mode actually switches**: The segmented pill opens the regex fields, and switching back to Simple restores the keyword.
- **Form controls more consistent and visible**: Inputs, dropdowns, steppers, and checkboxes share the form kit; checkboxes stay visible even when not hovered.
- **Right dock and selection more stable**: Empty dock shells are no longer a solid black panel, and narrowing the right pane no longer panics on selection column overflow.
- **macOS build fix**: Window extensions talk to winit directly again, so a fresh main checkout builds on Mac.
