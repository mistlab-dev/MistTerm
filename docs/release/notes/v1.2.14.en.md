# MistTerm 1.2.14

## Fixes

- **Delayed remote echo**: SSH output now requests a UI repaint as soon as it arrives, instead of relying on the cursor-blink timer. Typed characters that only appeared after moving the cursor (or looked like a hang) should show up promptly.

## Diagnostics

- To capture repaint-lag logs, create `~/mist-debug-log` before launching Mist. Logs go to `~/mist-repaint.log` (byte counts and timings only; no keystroke or terminal content). Remove the switch file when finished.
