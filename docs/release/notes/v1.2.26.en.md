# MistTerm 1.2.26

## What's New

- **Clearer opens with many hosts**: Tab-bar **+** picks a connection to open; sidebar and tab context menus offer **Open another tab**. The connection sidebar collapses after you open a host.
- **Welcome “New” matches sidebar**: Same primary/secondary button family as the connection panel.

## Fixes

- **Nested split orientation**: Top/bottom after left/right no longer inherits the parent direction; panes use absolute rects so left/right stays side-by-side.
- **Failure-card buttons work in splits**: Retry / Edit / Close are no longer blocked by a full-pane click layer; skip the duplicate failure toast when the card is already visible.
- **No surprise “Save as snippet?” toasts**: Removed auto candidate toasts from success/tail heuristics; save still via intercept toast or fragment analysis.
