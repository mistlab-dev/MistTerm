# MistTerm 1.2.22

## What's new

- **Better split panes**: left/right and top/bottom split, merge, and shortcuts show in the Terminal menu and tab context menu. New panes start in the current directory. Turn on Broadcast to type into every pane at once.
- **Welcome actions you can click**: Local terminal and New connection are on the welcome screen. The connection list opens by default, and activity-rail icons have short labels.
- **Clearer connection failures**: failed SSH tabs show a short message in the middle of the terminal instead of a blank screen. Handshake and banner errors are worded for people, not logs.

## Fixes

- **Prompt no longer clipped at the bottom of a split**: the last row keeps a gap above the window edge when you scroll to the end.
- **Double-click word select stops at colons**: clicking in `host:path` no longer grabs the colon and both sides together.
