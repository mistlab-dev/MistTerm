# MistTerm 1.2.20

## What's new

- **AI replies follow the UI language**: with the English UI, the AI assistant now answers in English (chat replies, explanations and plan descriptions). The Chinese UI is unchanged.
- **English AI panel**: the AI plan/confirm flow is fully English under the English UI — confirm hint, plan status, read-only "don't ask again" lines, policy explanations (risk cause, suggested alternative, run condition), host results, planner fallback notice and suggested next actions.
- **`mist` CLI help in English**: `mist --help` and every subcommand's help are English unless your locale (LC_ALL / LC_MESSAGES / LANG) is Chinese.

## Fixes

- **Empty "Suggested Commands" in AI chat**: commands such as `df`, `du`, `lsof`, `free`, `ps` and `journalctl`, and lists of six or more one-line commands, were dropped from AI replies. They now show up as runnable commands, and English section headings are recognised in any capitalisation.
- **Team command policy now applies to `mist ssh`**: commands typed in an interactive `mist ssh` session are checked against your team's policy on Enter, just like in the desktop terminal and `mist exec`. Blocked commands are not run; commands that need confirmation wait for `y`. Each decision is written to the audit log. Lines recalled from history and password prompts are not checked, same as the desktop app.
- **Secrets removed from AI context**: the recent-commands list sent with AI chat and the per-host results sent to the AI planner now go through the same redaction as terminal output (API keys, tokens, passwords, private keys). Redaction also now hides the token after `Bearer `.
- **"Attach session info" off now means nothing is attached**: with this setting off, AI chat no longer sends recent commands, terminal output, or host/user details.
