# MistTerm 1.2.38

## What's New

- **Local audit of interactive commands**: Commands submitted with Enter in the terminal go through the existing local audit and are written to `~/.mist/logs/exec-history.jsonl` (toggle in preferences; fullscreen, password lines, and multi-line pastes are not recorded).
- **Command palette**: When the terminal is unfocused, ⌘K / Ctrl+K opens a unified palette to search sessions, snippets, command history, and app actions.
- **OSC 133 command blocks**: Jump to the previous or next block and copy the current block (Ctrl+Shift+↑/↓/O; the shell must emit OSC 133).
- **Paste history**: Remembers the most recent pastes successfully written to the PTY (up to 20). Paste again with ⌘⇧P / Ctrl+Shift+P. Sensitive content is kept out when possible.
- **SFTP directory compare and one-way sync**: Compare local and remote differences, then copy the selection or everything one way. Conflicts are skipped and not overwritten.
- **`mist ssh --log-session`**: CLI interactive sessions write one JSONL record per command (default `~/.mist/logs/ssh-….jsonl`).
- **Idle cursor**: When connected, focused, and idle, the cursor redraws on its blink phase instead of a fixed ~60ms refresh.
