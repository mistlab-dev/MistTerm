# MistTerm 1.2.29

## What's New

- **Selection copy no longer adds padding**: Selecting and copying no longer pads trailing spaces, inserts a newline on a soft wrap, or inserts spaces between wide characters. Ctrl+Shift+C (⌘C on Mac), context-menu Copy selection, and Send to AI share that path.
- **Focused Alt / Option line-editing keys go to the shell**: Alt+B / Alt+F move by word, Alt+D / Alt+Backspace delete a word, and Alt+. inserts the previous command's last argument. MistTerm shortcuts no longer swallow these keys. On macOS this is Option.
- **Known limit**: Alt+click does not move the cursor, and MistTerm does not send the xterm mouse protocol, so tmux and vim mouse modes stay unavailable. The mouse is still for selecting text and scrolling.
