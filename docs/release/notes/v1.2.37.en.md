# MistTerm 1.2.37

## What's New

- **Crash reports on disk**: On panic, MistTerm writes a report under `logs/crash-reports/` (version, OS, thread, message, backtrace) so you can inspect crashes locally.
- **Anonymous usage ping**: When the startup update check runs, MistTerm also sends one anonymous ping to mistlab.dev (version / OS / arch / local random client id). Failures are silent and do not affect the app.
