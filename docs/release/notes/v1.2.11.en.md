# MistTerm 1.2.11

## Fixes

- **First terminal line no longer hidden**: The first line under the tab bar is fully visible with any font and size.
- **AI console**: The host status grid fits the panel; batch results keep the grid and red alert host after reopening a chat; "New chat" works; English leftovers in the Chinese UI are translated; quick prompts are disabled until AI is configured.

## Improvements

- **Consistent theme styling**: Light, Ocean and Forest now match the Dark theme for filter toggles, the active tab, selected rows and snippet tags.
- **One-click updates on macOS**: Starting with 1.2.11, the Mac app can update itself like on Windows. This takes effect from the next release; please install this one manually.
