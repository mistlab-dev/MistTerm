## 修复

- **Mac 上按 ⌘C 复制，提示「已复制」，剪贴板里却没有**：Windows / Linux 上的 Ctrl+Shift+C 也一样。在终端里选中文字后用快捷键复制，现在真的会放进剪贴板，再粘贴就是选中的内容。右键菜单里的「复制」一直是好的。这个问题从 1.1.4 起就有。
- **Windows / Linux 上 Ctrl+Shift+T、Ctrl+Shift+W、Ctrl+Shift+←/→ 按了没反应**：现在可以用快捷键新建标签、关闭标签、在分屏之间切换了。Mac 上的 ⌘T、⌘W、⌘⌥←/→ 不受影响。
- **片段快捷键会动到剪贴板**：如果片段的快捷键设在 ⌘⇧C、⌘⇧V、⌘⇧X 或 Ctrl+Shift+X 这类组合上，按下去除了运行片段，还可能顺带清空剪贴板或粘贴一次。现在只运行片段，不碰剪贴板。

## 说明

- **Ctrl+R 留给 shell**：终端里按 Ctrl+R 用的是 shell 自己的往回搜历史命令，Mist 不拦截。要打开 Mist 的命令历史面板，请用菜单 **工具 → 命令历史**。手册已经按这个改过来了。
