# MistTerm 1.3.3

## 更新内容

- **连接列表同机去重，时长更好读**：同一主机的重复条目会合并展示，在线时长改成人话表述，扫一眼更清楚。
- **片段面板清测试残留并补运维起步片段**：去掉正式库里残留的测试片段；若个人库是空的，会自动回填常用运维起步片段。
- **AI 危险命令先红框确认**：把危险终端命令填入或执行前，会弹出红色确认框，避免误操作。
- **SFTP 列宽、图标、路径与传输提示更顺手**：列宽与图标更清晰，路径更好认，上传/下载和拖拽也有更明确的提示。
- **监控告警通知、角标与偏好**：告警会走系统通知并显示角标，偏好里可按三档调节；断连错误更口语；告警阈值面板默认展开，方便改。
