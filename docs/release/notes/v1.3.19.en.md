# MistTerm 1.3.19

## What's New

- In the file panel, extra blank space between the title, path, and toolbar is gone, and so is the thin gap on the right edge
- In confirmation dialogs, Enter or Space activates the blue primary button
- When recording a command-snippet shortcut, modifier keys alone no longer end the recording early; you can finish and use combinations that include Shift
- The Fill Variables dialog puts the actual placeholder front and center, and the command preview updates as you type; if filling a field will not change the command, it tells you so
- When you edit a session that never saved a password, the password field is no longer pre-filled with a mask that looks like a saved password
- In Settings → About & Updates, unselected update channels show a visible radio ring
- IPv4 address dots in tabs and the connection list are easier to read, so 127.0.0.1 no longer looks like 127.0.01
- After you switch update channels, “Last checked” immediately shows that channel’s own status
- When you check for updates from Preferences, the Software Update dialog appears in front of the still-open Preferences window
- In the English UI, at the file panel’s default width, “Compare folders” is fully visible and clickable
- Chinese phrases in Operation Audit, Cloud Sync, and the file panel (for example, “审计目录”, “上传”, and “请换路径”) no longer break across lines mid-phrase
- When there are too many tabs, the tab bar can scroll left and right; a new or active tab scrolls into view so you can see and click it, without maximizing the window or collapsing the sidebar
