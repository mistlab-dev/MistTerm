# MistTerm 1.2.12

## Features

- **Local shell tab**: Terminal → Local Shell, or shortcut (Windows/Linux: Ctrl+Alt+T; macOS: ⌘⌥T). Opens the default local shell without saving a sidebar session.
- Local tabs reuse the existing terminal renderer; SFTP, port forwarding, and ZMODEM are unavailable (with a toast/panel message).

## Improvements

- Local shell tabs get a stable accent fill so they match SSH tab chrome on modern themes.
