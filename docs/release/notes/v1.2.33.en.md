# MistTerm 1.2.33

## What's New

- **Clearer update progress percent**: Software update, SFTP transfer, and rz/sz progress bars use theme progress colors instead of the selection tint, so the percentage stays readable.
- **SFTP file-type colors follow the theme**: Directory / executable / symlink colors live in the theme presets and switch with light/dark mode instead of hard-coded RGB.
- **Extension-point scaffolding**: Built-in module registry and Host hooks (`on_output_line` / `contribute_context_menu`) land, paving the way to move Trigger, display-link, and related features into modules.
- **Output Trigger**: Notify when a background tab finishes or errors (#112).
