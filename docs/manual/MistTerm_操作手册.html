1. MistTerm 是什么

MistTerm 是一款 SSH 终端客户端，日常用来：

  • 保存多台服务器连接，一键打开终端
  • 在图形界面里上传、下载文件（SFTP）
  • 保存常用命令模板（片段），少打重复命令
  • 把连上之后要按顺序敲的几行存成发送序列，在当前会话一键重放
  • 查看服务器 CPU、内存、磁盘等状态
  • 可选：AI 辅助解释命令、团队共享片段

支持 Windows、macOS 与 Linux。

2. 安装与启动

2.1 下载安装

  1. 打开 GitHub Releases
  2. 下载对应系统的安装包：
  3. Windows：MistTerm-*-windows-x86_64-setup.exe，双击安装
  4. macOS：.dmg，拖入「应用程序」文件夹
  5. 从开始菜单 / Launchpad 启动 Mist（或 MistTerm）

安装后无需单独安装 OpenSSH；连接远程 Linux 服务器即可使用。

2.2 首次启动

启动后会出现主窗口：左侧为活动栏（可打开连接列表与各面板），中间为工作区（连接后显示终端），顶部为菜单；提示信息以右下角 Toast 显示（无常驻底栏）。

图 2-1：已连接服务器时的主界面

2.3 数据保存在哪

连接、密码、片段等配置保存在本机用户目录（已加密），例如：

  • Windows：%APPDATA%\mistterm\
  • macOS：~/Library/Application Support/mistterm/

请勿手动编辑这些文件；在应用内修改即可。

4.3 命令面板

终端没有焦点时，按 Ctrl+K（macOS 为 ⌘K）打开命令面板。输入即可模糊搜索并执行：

  • 会话：已有标签则聚焦，否则连接
  • 片段：与快速片段选择器相同，选中后执行（有变量会先填写）
  • 命令历史：把命令填进终端输入行，不自动回车
  • 应用动作：打开 SFTP、监控、AI、端口转发、偏好设置、命令历史窗口、新建会话等

键盘：输入过滤，方向键上下，Enter 执行，Esc 关闭。面板打开时按键不会送进终端。

为什么不是 Ctrl+Shift+K： 终端失焦时 Ctrl+K / ⌘K 与系统快捷键不冲突，所以 Windows / Linux 仍用 Ctrl+K，macOS 用 ⌘K。终端聚焦时 Ctrl+K 仍然发给 shell，删到行尾（readline kill-to-EOL），面板不会抢走这个键。

快速片段选择器仍是 Ctrl+Shift+J，同样只在终端失焦时打开。

5. 连接服务器

5.1 新建会话

  1. Ctrl+N 打开对话框
  2. 填写：
  3. 会话名称：便于识别，如「生产 Web-01」
  4. 主机：IP 或域名
  5. 端口：一般为 22
  6. 用户名
  7. 密码 或 私钥文件路径
  8. 可选：取消勾选「使用 SSH Agent」若只用密码登录。要用硬件密钥时，认证方式选 FIDO2 / 安全密钥 (OpenSSH)（见 5.2.1）
  9. 点击 保存并连接

图 5-1：也可通过 终端 → 导入 SSH Config 从已有 ~/.ssh/config 批量导入

5.2 认证方式

方式 适用场景
密码 服务器允许密码登录
私钥文件 本机 .pem / id_ed25519 等
SSH Agent 已启动 ssh-agent / Pageant，密钥已加载
FIDO2 / 安全密钥 (OpenSSH) 已用 ssh-add 加载 ecdsa-sk 或 ed25519-sk。触摸和 PIN 由系统提示完成
跳板机 在高级选项中填写 ProxyJump（与 OpenSSH 相同）

5.2.1 FIDO2 / 安全密钥

会话认证方式选 FIDO2 / 安全密钥 (OpenSSH)。MistTerm 不自带 FIDO 协议栈，签名交给本机 OpenSSH agent（ecdsa-sk / ed25519-sk）。连接时窗口会提示触摸密钥或在系统提示里输入 PIN；取消触摸、PIN 错误、代理里没有密钥或密钥文件找不到，都会显示失败原因，不会当成已登录。密码和普通密钥在这条路径上不会被拿来顶替。

下面是三端各自的最短步骤。只保证 OpenSSH 能驱动的安全密钥（常见是带 ed25519-sk / ecdsa-sk 的 FIDO2 密钥，例如部分 YubiKey 5），不表示每一款硬件都可用。三端都能完成登录。

Windows

  1. 安装 OpenSSH 客户端，并把服务 OpenSSH Authentication Agent（ssh-agent）设为自动并启动。Pageant 不能为 sk 密钥签名。
  2. 在 PowerShell 中：ssh-keygen -t ed25519-sk -f $env:USERPROFILE\.ssh\id_ed25519_sk（也可用 -t ecdsa-sk）。按提示触摸密钥；若要 PIN，在系统提示里输入。
  3. ssh-add $env:USERPROFILE\.ssh\id_ed25519_sk。密钥只放在硬件里时，用 ssh-add -K。
  4. MistTerm 里把认证方式选成 FIDO2 / 安全密钥，路径可留空（用代理里的 sk 密钥）或填上面的文件。保存并连接，按窗口和 Windows 提示触摸或输入 PIN。

macOS

  1. 系统自带 ssh-agent。终端执行：ssh-keygen -t ed25519-sk -f ~/.ssh/id_ed25519_sk。
  2. ssh-add --apple-use-keychain ~/.ssh/id_ed25519_sk（或 ssh-add ~/.ssh/id_ed25519_sk）。
  3. MistTerm 里选择 FIDO2 / 安全密钥并连接。密钥闪烁时触摸；需要 PIN 时在 macOS 提示里输入。

Linux

  1. 需要 OpenSSH 8.2 或更新（ssh -V）。在启动 MistTerm 的同一个图形会话里运行 OpenSSH 的 ssh-agent，并让进程继承 SSH_AUTH_SOCK。桌面自带的 gnome-keyring SSH 组件不一定能签 sk 密钥，请用 OpenSSH 的 ssh-agent。
  2. ssh-keygen -t ed25519-sk -f ~/.ssh/id_ed25519_sk，然后 ssh-add ~/.ssh/id_ed25519_sk。
  3. 若密钥每次都要 PIN，而 agent 没有终端：启动 agent 之前设置 SSH_ASKPASS（例如 ssh-askpass）和 SSH_ASKPASS_REQUIRE=force，PIN 会出现在图形提示里。
  4. MistTerm 里选择 FIDO2 / 安全密钥并连接，按提示触摸或输入 PIN。

5.3 连接与重连

  • 连接：侧栏单击选中 → Ctrl+T 新标签，或双击会话
  • 搜索会话：终端失焦时 Ctrl+J 聚焦侧栏搜索框（终端聚焦时 Ctrl+J 发给 shell）
  • 自动重连：在会话编辑里可开启 KeepAlive / 自动重连
  • 连接成功后，标签上会显示在线圆点；提示信息以右下角 Toast 显示

5.4 本地数据安全

密码和会话信息在本地加密保存，换电脑需重新配置或恢复备份。配置文件为加密格式，用记事本打开会看到乱码，属正常现象。

6. 使用终端

6.1 基本操作

  • 连接成功后直接在终端区输入命令，Enter 执行
  • Ctrl+C 始终中断前台程序（SIGINT），有选区时也一样。复制选区：Windows / Linux Ctrl+Shift+C，Mac ⌘C。粘贴：Ctrl+Shift+V（Mac：⌘V）
  • Ctrl+K（终端聚焦）：发给 shell，删到行尾。Ctrl+J（终端聚焦）：发给 shell（换行，与 readline 一致）。连接搜索（Ctrl+J）和命令面板（Ctrl+K，Mac 为 ⌘K）只在终端失焦时生效。失焦 Ctrl+K 与系统不冲突，因此不用 Ctrl+Shift+K。快速片段选择器是 Ctrl+Shift+J，同样只在失焦时打开
  • Alt（macOS 为 Option）在终端聚焦时作为 Meta 发给 shell：Alt+B / Alt+F 按词跳转，Alt+D / Alt+Backspace 按词删除，Alt+. 插入上一条命令的最后一个参数（连按可循环更早的参数）。这些键不会被界面快捷键吃掉
  • 跨多屏选择：单击起点 → 滚轮翻到终点 → Shift+单击终点即可扩展选区；拖选时把鼠标移到终端上/下边缘外会自动滚动，越远越快。之后右键「复制选中」或 Ctrl+Shift+C（Mac：⌘C）复制全部内容
  • 中文输入：合成过程中，预编辑文字显示在光标处；候选窗由系统输入法面板显示。合成中的 Ctrl+C、Ctrl+R 等 Ctrl 组合仍发给终端，不交给拼音编辑
  • 支持彩色输出、vim、htop 等常见 TUI 程序
  • 标签页：Ctrl+T 新开标签；Ctrl+W 关闭当前标签；Ctrl+Tab 切换标签

6.2 查找与历史

  • F3 或 Ctrl+F：在终端输出中查找文字

  • Ctrl+R（终端聚焦）：发给 shell，进入反向搜索（reverse-i-search），不会打开 Mist 命令历史面板
  • 工具 → 命令历史：打开 Mist 的命令历史面板，搜索并重新执行最近的命令。终端失焦时 Ctrl+R 也会打开该面板
  • Ctrl+Shift+P（Mac：⌘⇧P）或 工具 → 粘贴历史：打开粘贴历史，把最近成功送进终端的粘贴再贴一次（默认记住 20 条）。一次粘贴仍是 Ctrl+Shift+V（Mac：⌘V），不会改成打开这个面板。私钥、常见令牌和密码/口令提示会尽量不记住；这是尽力过滤，并不完备。可在偏好设置里关闭「记住最近的粘贴」

6.3 分屏（同一标签多窗格）

菜单 终端 里也有这几项。标签上右键同样可以分屏。

Windows 与 Linux 用 Ctrl+Shift，macOS 用 ⌘⇧。

  • Ctrl+Shift+D（macOS ⌘⇧D）：左右分屏
  • Ctrl+Shift+U（macOS ⌘⇧U）：上下分屏
  • Ctrl+Shift+← / Ctrl+Shift+→：在分屏窗格间切换焦点（macOS 为 ⌘⌥← / ⌘⌥→）
  • 新窗格从当前窗格所在目录启动（本机终端、以及 Linux / macOS 的 cd，Windows 远程的 PowerShell）
  • Ctrl+Shift+B（macOS ⌘⇧B）：同时输入。打开后，键入会发到这个标签里的每个窗格。窗格标题右侧会显示「同时输入」

6.4 已知限制：鼠标与 Alt+点击

鼠标在终端里用来拖选文字和滚动。下面两项当前不做，不是偶发故障：

  • 不支持 Alt+点击把光标移到点击的位置（shell 行内也不会因此跳动）
  • 不向 PTY 发送 xterm 鼠标协议。tmux、vim 等的鼠标模式因此不可用：在画面上点击、拖动，远端收不到鼠标报告

6.5 命令块

一条命令和它的输出可以收成一块，用来上一条 / 下一条跳转，或一次复制「命令 + 输出」。分界只认 shell integration 发出的 OSC 133（VS Code 的 OSC 633 同样认）。没有这些标记时，不会根据回车或提示符去猜，vim / less / htop 的全屏画面也不会被收成一块。

最短启用

  • 本机已经开了 iTerm2 或 VS Code 的 shell integration：保持启用即可。
  • bash，写入 ~/.bashrc：
__mist_cmd_block() {
  local ec=$?
  printf '\e]133;D;%s\a' "$ec"
  printf '\e]133;A\a'
}
PROMPT_COMMAND="__mist_cmd_block${PROMPT_COMMAND:+;$PROMPT_COMMAND}"
PS1="${PS1}"'\[\e]133;B\a\]'
  • zsh，写入 ~/.zshrc（若已有 precmd / preexec，把下面两行 printf 加进现有函数）：
precmd() {
  local ec=$?
  printf '\e]133;D;%s\a' "$ec"
  printf '\e]133;A\a'
}
preexec() { printf '\e]133;C\a'; }
PS1="${PS1}"'%{\e]133;B\a%}'

C（命令已提交）可以不发。只发 A / B / D 时，命令结束后仍是一块。新开一个终端标签后生效。

怎么用（终端要处于焦点；Windows / Linux 为 Ctrl+Shift，macOS 为 ⌘⇧）

  • Ctrl+Shift+↑：上一条命令块
  • Ctrl+Shift+↓：下一条命令块。过了最后一条回到最新输出
  • Ctrl+Shift+O：复制当前命令块（从提示符结束到命令结束；还在跑的命令复制到光标）
  • 终端右键菜单里也有这三项。没启用时会提示来看本节，画面不滚动，快捷键也不会发给 shell

复制最多保留开头 4000 行、200000 个字符，更长会截断并注明。进入 vim / less 的那条命令仍是一块，复制内容不含全屏画面。

7. 传输文件

7.1 SFTP 面板（推荐）

打开方式：菜单 视图 → SFTP，或左侧活动栏「文件」。

界面分为本机与远端两栏：

  1. 路径框改目录后按 Enter 跳转；旁边 ☆ 可收藏，路径 下拉可打开收藏/最近
  2. 路径下方可按文件名筛选（只影响当前列表）
  3. 单击选中；Ctrl/⌘ 加选；Shift 范围选。文件夹上传/下载会保持相对路径
  4. 工具栏或右键：上传、下载、删除、新建文件夹、重命名、编辑（远端文本）、权限
  5. 传输时底部显示进度与速度，可取消；同名时可选覆盖 / 续传 / 跳过（及「全部」）
  6. 操作结果以右下角 Toast 提示

典型流程 — 上传文件到服务器：

  1. 连接 SSH 后打开 SFTP 面板

7.2 终端内 ZMODEM（rz / sz）

若服务器已安装 lrzsz，可在终端里：

# 从本地上传文件到当前远程目录（执行后按提示选择文件）
rz -bye

# 从远程下载文件到本机
sz 文件名

MistTerm 会自动接管传输并显示进度。若传输异常，请确认远端使用 rz -bye，并检查防火墙是否中断长连接。

8.2 使用变量

若已登录 MistLab 团队账号，可使用团队共享片段（见第 11 节）。

团队片段支持 admin / editor / viewer 角色权限，并支持针对单个成员覆盖角色权限。编辑团队片段时会自动取得编辑锁；异常退出后，客户端会在下次启动或登录时清理本人残留的编辑锁。

9. 监控与端口转发

9.1 主机监控

  1. 先建立 SSH 连接
  2. 打开 视图 → 监控 或活动栏「监控」
  3. 查看 CPU、内存、磁盘、负载等图表（数据来自远程服务器，只读采集）

图 9-1：主机监控

监控依赖 SSH 连接。若连接断开，图表会停止更新；重新连接即可。

12. 命令安全提示

MistTerm 有两层命令安全检查：本地检查用于快捷提示，服务器侧团队策略才是部署了 Agent 时的权威判定。两者都在危险命令实际发送或执行前给出提示或拦截：

行为 说明
拦截 如 rm -rf / 等极高风险命令无法发送
确认 弹窗询问「是否继续」
告警 允许执行但记录告警

本地检查覆盖片段执行、批量执行、AI 填入的命令、mist exec、发送序列里的每一非空行，以及在终端里直接手敲的命令：本地策略生效时，按 Enter 前会先检查当前这一行（包括「用到终端」放进来的内容和单行粘贴），被拦截时回车不会发出，命令留在输入行里；需确认时点「确认发送」才会执行。以下情况手敲命令不做本地检查，回车照常发送：vim/less/top 等全屏程序里、密码或口令提示行、rz/sz 传输进行中。用方向键、Tab 补全或历史回忆改过的行，客户端只能看到你实际敲入的字符，以服务器侧策略为准。

可在 偏好设置 中查看或调整本地规则。加入团队后，管理员下发的策略会同步到本机；服务器侧 Agent 的判定会通过终端连接回传，客户端会显示「服务器策略」前缀。

12.1 服务器侧拦截与合规替代

当服务器侧策略拦截命令时：

  1. block：显示「服务器策略：该命令被禁止」，原命令不会发送。
  2. confirm：显示确认弹窗，选择「放行并发送」后才会继续发送。
  3. alert：允许执行，同时记录团队审计事件。
  4. 若团队或个人片段库中存在相关的安全操作，拦截提示会优先推荐合规替代片段，可直接插入当前终端；团队片段还可以沉淀到个人库。

本地规则对应的提示使用「本地检查」前缀。客户端不会通过 AI 提供绕过团队策略的做法；AI 建议也不会替代服务器侧策略判定。

12.2 Agent 不可用

客户端会定期检查当前主机的 Agent 心跳。Agent 离线或超过约 5 分钟没有心跳时，终端顶部会显示黄色提示；Agent 恢复后会显示恢复通知。此时本地提示仍可工作，但服务器侧强制审计不可视为可用，应联系团队管理员处理。

13.2.1 崩溃与卡顿报告

进程 panic 时，报告写在配置目录的 logs/crash-reports/（与 logs/hang-reports/ 同级）。下次打开时，若这份报告比上次正常退出更新，或上次没有正常退出且已有报告，会弹一次摘要（版本、时间、panic 首行），可打开目录或复制全文。第一次安装不提示。之后如果进程被强制结束或发生没有报告的原生崩溃（例如 SIGSEGV），下次仍会提示一次，说明没有新的崩溃报告。正常退出后再打开则不提示。

帮助 → 诊断 可随时打开「崩溃报告目录」和「卡顿报告目录」。Rust panic 能落盘；原生 SIGSEGV 目前没有本机报告文件。

13.5 发送序列

工具 → 发送序列（命令面板里单独一类「发送序列」，不是「片段」）把几行文字按顺序发进当前这一个已连接窗格。

  1. 新建并命名
  2. 每行一条要发出的文字。空行就是按一次回车
  3. 可选行间间隔（毫秒）。0 表示上一行发出后马上发下一行。只做固定等待，不会等远端出现提示符
  4. 保存
  5. 先连上会话，再点 发到当前会话

即使当前标签开了「同时输入」，发送序列也只进入当前窗格，不会发到其它窗格或其它标签。

本地命令策略生效时，每一非空行会先做和手敲回车一样的检查。被禁止的行不会发出，后面的行也不再发。需要确认时，确认之后才继续。

15. 常见问题

无法连接服务器

  • 检查主机、端口、用户名、密码/密钥是否正确
  • 确认本机网络能访问目标 IP（可先用系统自带 ssh 命令测试）
  • 若需跳板机，在会话高级选项中配置 ProxyJump
  • 查看右下角 Toast 是否显示错误信息

连接后终端空白或乱码

  • 稍等几秒等待 shell 初始化
  • 在偏好设置中确认语言与字体；中文环境一般会自动选用合适字体

SFTP 无法上传/下载

  • 确认 SSH 已连接成功（同一标签页）
  • 检查远程目录是否有写权限
  • 本机目标路径是否存在、是否只读

ZMODEM（rz/sz）传文件失败

  • 确认服务器已安装 lrzsz（which rz）
  • 上传时使用 rz -bye
  • 传输过程中勿切换标签或断开连接

配置文件打开是乱码

  • 正常现象：MistTerm 对本地配置做了加密，请只在应用内修改

如何卸载

  • Windows：设置 → 应用 → MistTerm → 卸载
  • macOS：将 MistTerm 拖入废纸篓；配置仍在 Application Support/mistterm/，可手动删除

如何反馈问题

前往 GitHub Issues 描述现象、版本号与操作系统，勿在 issue 中粘贴密码或密钥。
